**Deskripsi Proyek**

Sistem PPDB Digital berbasis IoT dengan Verifikasi QR Code dirancang untuk mempermudah proses pendaftaran dan verifikasi siswa baru secara cepat, aman, dan terintegrasi.
Siswa melakukan pendaftaran melalui formulir online dan akan memperoleh QR Code unik sebagai bukti pendaftaran. QR Code tersebut kemudian diverifikasi menggunakan perangkat IoT melalui proses pemindaian.

**Teknologi QR Code**

Pembuatan QR Code pada sistem ini menggunakan library open-source PHP:

php-qrcode by chillerlan

Repository: https://github.com/chillerlan/php-qrcode

License: MIT

Library ini digunakan untuk menghasilkan QR Code secara dinamis dan efisien pada proses pendaftaran siswa.
